> A private ecosystem of Telegram automation — scrapers, encoders, uploaders and posters
> wired into hands-off pipelines. `nyaa RSS ─▶ encode ─▶ store ─▶ post` while I sleep.

### 🎌 Anime & Media Automation Suite

| Bot | What it does |
|:----|:-------------|
| **Auto-Ongoing** | Watches `nyaa.si` RSS → leeches through a fleet of encoders → stores via file-store bot → posts poster + quality buttons to each anime's channel, fully hands-off. |
| **AutoFinished** | Completed-anime poster pulling **6 sources** (animetoki · puretoons · animevilla · toonworld4all · moviesmod · nyaa), one post per season, sticker-separated. |
| **AutoAniMovie** | Semi-auto anime **movie** poster — AniList lookup + TMDB title-art backdrops, magnet/DDL → 3 qualities → formatted release. |
| **AutoSeries** | `moviesmod.zone` movie/series leech + poster with a full HTTP link-bypass chain (modpro → unblockedgames → driveseed → r2), live preview + manual-add editor. |
| **AutoNews** | Anime-news auto-poster classifying stories into 16 categories, enriched via AniList, pushed using Telegram **Rich Messages** (real headings) + trailer video. |
| **AutoManga** | Private manga bot — subscribe to a title, it watches for new chapters and DMs a built **PDF/CBZ** (watermark, compression, password). |

### ⚙️ Infrastructure & Utility

| Bot | What it does |
|:----|:-------------|
| **TZML** | Mirror / leech powerhouse (WZML-X fork) — internet → Google Drive / Telegram / any RClone remote. |
| **GoatEncoders** | 480p / 720p / 1080p FFmpeg encoder fleet feeding the anime pipelines. |
| **IDCopier** | Channel cloner that **preserves every message ID**, so old `t.me/c/…` and file-store deep links keep resolving. |
| **File-Sequence** | Reorders messy anime/series files into perfect `season → quality → episode` order with a teachable `/regex` naming engine. |
| **RequestAcceptor** | Auto-approves channel join requests and DMs a customizable welcome (media + URL buttons). |
| **Infinite** | Multi-instance file-store & deep-link fleet powering the store/link layer behind the posters. |
